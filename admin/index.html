행사 운영·회원 담당

행사 참여 상태, 공지, QR별 운영 상태, 회원 권한·차단, 수동 진행 처리와 감사 기록을 관리합니다.

담당 페이지 열기 → 진행률·상품 수령 담당

참여 현황, 완주 여부와 상품 수령 처리를 확인하고 CSV로 내보냅니다.

담당 페이지 열기 → QR 제작 담당

일반·스토리 모드 QR을 만들고 인쇄용 파일을 준비합니다.

담당 페이지 열기 → 1:1 문의 담당
